# Spring Boot Essentials — Estudos

Repositório dedicado aos meus estudos de desenvolvimento Back-end com Java e Spring Boot, acompanhando o curso Spring Boot Essentials, do DevDojo.

## Tecnologias

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Git e GitHub

## O que estou aprendendo

- Criação de APIs REST
- Operações CRUD
- Persistência de dados com JPA
- Integração com MySQL
- Tratamento de exceções e erros HTTP
